# Snow Leopard desktop asset sources

Assets in `dist/assets/snow-leopard/` are historical Apple artwork, not generated approximations. Downloaded images are preserved without visual edits. These links record provenance; they do not grant a new license to the original Apple artwork.

## Wallpaper

- `wallpaper.jpg`: [original attachment](https://forums.macrumors.com/attachments/snow-leopard-jpg.694748/), 2560 × 1600 JPEG. The [uploader’s discussion](https://forums.macrumors.com/threads/project-complete-collection-of-mac-os-wallpapers-updated.2036834/) identifies it as extracted from the retail Mac OS X 10.6.0 DVD. This is the animal portrait, not the Aurora desktop background, and predates the retouched 10.6.3 version.

## Interface reference

[Safari 4 final release coverage, June 2009](https://arstechnica.com/gadgets/2009/06/safari-4-final-no-tabs-and-performance-updates-for-106/) distinguishes the final release’s tabs below the toolbar from the beta’s title-bar tabs. [Cult of Mac’s September 2009 gallery](https://www.cultofmac.com/news/icon-porn-feast-your-eyes-on-snow-leopards-beautiful-icons) provides contemporary visual references for Safari, Mail, Dashboard, System Preferences, TextEdit and iTunes.

The refined menu bar follows the user's Snow Leopard installer screenshot: a smooth opaque silver gradient, dark Lucida Grande type, and a glossy Apple mark. The notch shares its 23px height and menu labels stay clear of it at responsive breakpoints.

The Apple mark uses the Lucida Grande U+F8FF glyph outline as vector paths, with a black leaf, black upper body, gray lower body, and a one-pixel pale underside reflection. Its proportions and shading are matched to the [original Snow Leopard desktop capture](https://media.512pixels.net/downloads/macos-screenshots/10-6/10-6-Snow-Leopard-Desktop.png); no font file is distributed.

The compact, unified Safari chrome and drawn SVG controls use [Version Museum's Snow Leopard Safari capture](https://www.versionmuseum.com/images/operating-systems/mac-os-x/mac-os-x%5E2009%5E10.6-snow-leopard-safari-browser-nyt.jpg) from its [Mac OS X history](https://www.versionmuseum.com/history-of/mac-os-x), with supporting AppKit geometry from [512 Pixels' Snow Leopard screenshot library](https://512pixels.net/projects/aqua-screenshot-library/mac-os-x-10-6-snow-leopard/) and its [Safari 5 capture](https://media.512pixels.net/downloads/macos-screenshots/10-6/10-6-Snow-Leopard-Safari-v5.png). Reference screenshots are not bundled in the public site.
# Sound effects

The Fuzzy, Rubber, and Arcade cues in `dist/assets/sounds/` were rendered and mixed using [Earshot](https://github.com/Leonxlnx/earshot), commit `591fa3e028032e6dce56620a20e932e35667e8d8`. They use procedural bank recipes, with no source recordings. Reproduction details and measured audio checks are in `../sound-design/README.md` and `../sound-design/sound-report.json`. Earshot's MIT notice accompanies the WAVs.


## GitHub desktop shortcut

`github-snow-leopard.svg` is an original Aqua-style glass-and-chrome desktop icon. It incorporates the GitHub mark from [Octicons](https://github.com/primer/octicons/blob/9c3c9d7426881584f6f507f3f4a54aea5879648e/icons/mark-github-24.svg), pinned to commit `9c3c9d7426881584f6f507f3f4a54aea5879648e`. The [Octicons MIT license](dist/assets/Octicons-LICENSE.txt) is included beside the asset. The GitHub name and mark retain their trademark status.
